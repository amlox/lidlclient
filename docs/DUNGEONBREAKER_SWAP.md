# Dungeonbreaker swap

In Options > Controls > Key Binds > LidlClient, bind **Dungeonbreaker swap**.
It is unbound by default. Put Dungeonbreaker in any of the nine hotbar slots and
press the key to select it. Matching ignores capitalization and legacy color codes,
and supports reforged names and "Dungeon Breaker" with a space.

If multiple matches exist, the already selected matching slot is kept; otherwise
the leftmost match is selected. A missing item shows an action-bar message.
The key does nothing while a GUI is open or the player is disconnected.

This ports only the manual item swap. It does not click, break blocks, switch to a
pickaxe, swap back, run timers or move items from the main inventory.
