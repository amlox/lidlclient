# Dungeonbreaker swap

Open /lidl > General, right-click **Dungeonbreaker swap**, then click **Keybind**.
Press the keyboard key or mouse button you want to use. Escape cancels capture;
Backspace, Delete, or right-clicking the Keybind row clears the binding.
Bindings save immediately and survive restarts. The module can be toggled on/off.

Put Dungeonbreaker in any hotbar slot and press the chosen key to select it.
Matching ignores case and color codes and supports reforged names or "Dungeon Breaker".
If multiple items match, the selected matching item stays selected; otherwise the
leftmost hotbar match is selected. Missing items show an action-bar message.
The key does nothing while a GUI is open or the player is disconnected.

This ports only the manual item swap. It does not click, break blocks, switch to a
pickaxe, swap back, run timers or move items from the main inventory.
