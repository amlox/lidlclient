# Built-in features

Open `/lidl > General settings > Built-in features`. Left-click the module to
switch all shipped presets and the warp shortcut on/off. Right-click for separate
**Player sizes**, **Name aliases**, and **Warp shortcut** switches. All default to
on so updating preserves existing behaviour. The master switch remembers the
individual choices and does not erase them.

Disabling built-in sizes restores normal 1x sizes; disabling built-in aliases
restores real names. Your custom self size and name modules remain independent,
and their saved overrides still work. Name changes refresh existing chat as well
as new rendering. The warp shortcut sends no command while disabled.

All controls save in `config/lidlclient.json` and take effect without restarting.

# Green strength

Under `/lidl > Fun features`, right-click the green module to reveal **Green
strength (%)**. It ranges from 0% (transparent) to 100% (solid green), in 1% steps.
The default is 35%, matching the previous tint. The module toggle still switches
the entire effect on/off, while retaining the saved strength.
